Fairy's tool calls read as what it did: 创建机器人 小助手 rather than bots.create, with the id on hover. Each kind opens its own way: a command with its exit code and the end of its output, a file read with line numbers or an edit as a diff, a web page with its title and content, a question with every option and the one you picked, and other calls as fields with the rest folded in a tree. Waiting calls are yellow, finished ones quieter, failed ones red with the reason, declined ones struck out; a question shows where Fairy asked it. Model and effort are two buttons above the input: models by provider in groups that fold and stay as you left them, a pick that keeps the list open, an effort slider, and "Set as Fairy default", which /model opens too.
